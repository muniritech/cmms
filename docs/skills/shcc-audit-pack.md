# SHCC Audit Pack Skill

Structure for the audit pack export.

## Contents
1. Biomedical Equipment Register
2. PPM Schedule Chart (printable, month-by-month)
3. Service / Calibration Certificates file
4. Breakdown Register

## Critical Rule
Every SHCC-related item must be marked: **"To be verified against the official SHCC checklist"**.
Design structure so it can be adapted when the real checklist is obtained.

## Verification Path
- User has nothing on SHCC currently.
- Must verify with Sindh Healthcare Commission or hospital legal/regulatory contacts before finalizing audit requirements.
